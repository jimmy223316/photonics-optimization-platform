# Dataset provenance

`synthetic_coupling.csv` is a 3×3 grid evaluated with the repository's Gaussian toy objective. It contains illustrative `offset_um` and `angle_deg` parameter columns and `coupling_efficiency` fractions. It is generated by `python scripts/generate_csv_example.py` and has no solver or experimental origin.

Use it to exercise the external-result import format, summary analysis, and exact CSV replay backend. It is **not** an example of real Lumerical data. No external scientific dataset is bundled.

For your own exports, include one column per parameter and a scalar efficiency column. Convert percentages to fractions before import. Select parameter columns explicitly; extra metadata columns are allowed but are not retained in records. Track geometry, wavelength, units, solver/version, normalization, and validation evidence separately. Importing data never establishes scientific validation.

`synthetic_width.csv` demonstrates a different schema with `width_nm`, a custom `eta` efficiency column, and metadata. Values are generated by the arbitrary analytic function `exp(-0.5*((width_nm-500)/100)^2)` at widths 300–700 nm; the unit label is illustrative, with no device calibration. Analyze it with `photonics-analyze examples/datasets/synthetic_width.csv --parameters width_nm --efficiency-column eta --data-kind synthetic_analytic_toy`.
